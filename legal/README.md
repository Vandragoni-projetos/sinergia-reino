# Diretório de Páginas Legais

Este diretório contém as páginas HTML geradas automaticamente para Política de Privacidade e Termos de Serviço.

## Arquivos Gerados

- `privacidade.html` - Política de Privacidade
- `termos.html` - Termos de Serviço

## Como Gerar

As páginas são geradas automaticamente através do Editor de Checkout:

1. Acesse o Editor de Checkout de um produto
2. Role até a seção "Links Legais"
3. Clique no botão "Gerar Página" ao lado do campo desejado
4. A URL será preenchida automaticamente
5. Salve as configurações do checkout

## Personalização

As páginas geradas incluem automaticamente:
- Logo do sistema (configurado em Configurações do Sistema)
- Nome da plataforma
- Favicon
- Conteúdo pré-determinado em português brasileiro

## Conteúdo

O conteúdo das páginas é baseado em templates padrão que incluem:

### Política de Privacidade
- Informações coletadas
- Como usamos as informações
- Compartilhamento de dados
- Segurança dos dados
- Direitos do usuário (LGPD)
- Cookies e tecnologias similares
- Retenção de dados

### Termos de Serviço
- Aceitação dos termos
- Descrição do serviço
- Cadastro e conta de usuário
- Uso aceitável
- Produtos e pagamentos
- Propriedade intelectual
- Limitação de responsabilidade
- Lei aplicável

## Observações

- As páginas são geradas em HTML estático
- Podem ser editadas manualmente se necessário
- São acessíveis publicamente via `/legal/privacidade.html` e `/legal/termos.html`
- Recomenda-se revisar o conteúdo e adaptá-lo às necessidades específicas do negócio
